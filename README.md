# WANTD — E-commerce Storefront

WANTD is a modern, Gen-Z-inspired e-commerce storefront built with React, JavaScript, and plain CSS.

## Features

- Product browsing and product details
- Shopping cart and quantity controls
- Wishlist
- Checkout form with validation
- Order confirmation and order history

## Tech Stack

- React
- JavaScript (JSX)
- CSS
- Vite
- TanStack Start

## Run Locally

**Requirements:** Node.js 18 or later and npm.

1. Clone this repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL displayed in your terminal.

## Project Structure

- `src/wantd/` — storefront components, pages, data, context, and styles
- `src/routes/` — application routes
- `public/` — static assets
